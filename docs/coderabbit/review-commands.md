# CodeRabbit Review Commands

Use these commands by mentioning `@coderabbitai`.

Most commands go in a PR comment. `ignore` is the exception.

## Trigger A Review

```text
@coderabbitai review
```

Incremental review focused on new changes.

```text
@coderabbitai full review
```

Fresh review of the entire PR.

## Control Auto Reviews

```text
@coderabbitai pause
```

Pause automatic reviews for the PR.

```text
@coderabbitai resume
```

Resume automatic reviews for the PR.

## Ignore This PR (PR Description Only)

Put this in the PR description (not in a comment):

```text
@coderabbitai ignore
```

To re-enable, remove it from the description.

## Resolve CodeRabbit Comments

```text
@coderabbitai resolve
```

Resolves all CodeRabbit comments on the PR.

## See Active Configuration / Help

```text
@coderabbitai configuration
```

Show the active CodeRabbit configuration for the PR.

```text
@coderabbitai help
```

Show available commands.
